⚡ System Requirements
NexoLLM automatically selects the best quantised model for your computer's memory and power state.
  • Processor: 64-bit CPU (`x86_64` or `ARM64`)
  • Memory: 8 GB RAM minimum (Gemma 4 E2B / Qwen 3B); 16 GB RAM recommended (Gemma 4 E4B)
  • Storage: ~150 MB for the app + 1.9–5.3 GB for your chosen local GGUF model
  • Network: Not required for writing; used only when downloading models, checking signed updates, or pressing ⌃⌥L Web Lookup
